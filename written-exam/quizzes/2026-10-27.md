## 20261027-01 · 两个独立信号的 p-value 能直接相乘吗？

**难度：★★☆☆☆｜建议用时：5–10 分钟**  
**核心考点：Probability Transformations · CDF · Gamma/Chi-Square · Hypothesis Testing**

你在研究两个不同的 Alpha 信号。为了简化，假设在零假设 $`H_0`$（两个信号都没有预测能力）成立时，它们对应的 p-value 为：

```math
U_1,U_2\overset{\mathrm{iid}}{\sim}\mathrm{Uniform}(0,1).
```

你尝试使用乘积 $`W=U_1U_2`$ 作为联合显著性指标，数值越小表示越显著。

### 1. 乘积分布

求 $`W`$ 的 CDF，即 $`F_W(w)=P(W\le w)`$，并给出完整的分段定义。

### 2. 误报概率

如果错误地把 $`W<0.05`$ 当作 5% 显著性水平的拒绝规则，真实的第一类错误概率是多少？

### 3. 变换后的统计量

定义 $`Z=-2\log(U_1U_2)`$。求 $`\mathbb E[Z]`$、$`\mathrm{Var}(Z)`$，并指出 Z 的分布。

### 4. 推广

对 m 个相互独立且在零假设下服从 Uniform(0,1) 的 p-value，令 $`Z_m=-2\sum_{i=1}^m\log U_i`$。求 Z_m 的分布。

**附加挑战：** 若这些 p-value 的边际分布仍为 Uniform(0,1)，但彼此相关，第四问是否仍成立？举出一个极端相关的反例即可。

## 20261027-02 · 只观察到样本最大值，如何估计未知上界？

**难度：★★★☆☆｜建议用时：10–15 分钟**  
**核心考点：Maximum Likelihood · Order Statistics · Bias Correction · Confidence Interval**

有 n 个独立同分布观测，满足 $`n\ge2`$ 且：

```math
X_1,\ldots,X_n\overset{\mathrm{iid}}{\sim}\mathrm{Uniform}(0,\theta),
\qquad \theta>0.
```

参数 θ 未知，是均匀分布的上界。记样本最大值为 $`M=\max_i X_i`$，样本均值为 $`\bar X`$。

### 1. MLE

写出似然函数 $`L(\theta;X_1,\ldots,X_n)`$，求最大似然估计 $`\hat\theta_{\mathrm{MLE}}`$。注意参数对样本支持集的约束。

### 2. 偏差

求 M 的分布、$`\mathbb E[M]`$ 和 $`\mathrm{Var}(M)`$，据此构造基于 M 的无偏估计量 $`\tilde\theta`$。

### 3. 效率比较

$`2\bar X`$ 也是一个无偏估计量。比较 $`\tilde\theta`$ 与 $`2\bar X`$ 的方差，判断哪个估计量更有效。

### 4. 精确置信界

构造单侧 95% 置信上界 $`U(M)=c_nM`$，使得对每个 $`\theta>0`$：

```math
P_\theta\bigl(\theta\le U(M)\bigr)=0.95.
```

求 $`c_n`$。若 $`n=5`$ 且观察到 $`M=8`$，写出对应的置信上界表达式。

**附加挑战：** M 是否是 θ 的充分统计量？尝试用 Neyman–Fisher Factorization Criterion 说明。

## 20261027-03 · 你能比最好的 Alpha 专家少亏多少？

**难度：★★★★☆｜建议用时：15–20 分钟**  
**核心考点：Online Learning · Exponential Weights (Hedge) · Regret · Potential Function**

你有两个预先固定的交易预测模型（专家）A 和 B。每天开盘前必须确定依赖两个模型的权重；收盘后，无论当天采用了哪个模型，**都可以观察到两个模型当天的损失**。

第 t 天专家 i 的损失为 $`\ell_{i,t}\in[0,1]`$，赋予其权重 $`p_{i,t}\ge0`$，满足 $`\sum_i p_{i,t}=1`$。算法当天的损失定义为：

```math
\hat\ell_t=\sum_{i\in\{A,B\}}p_{i,t}\ell_{i,t}.
```

所有权重必须在观察当天损失之前确定。

考虑 Exponential Weights (Hedge) 算法。初始权重均为 1，学习率 $`\eta>0`$，使用以下规则：

```math
w_{i,t}=\exp\left(-\eta\sum_{s=1}^{t-1}\ell_{i,s}\right),
\qquad
p_{i,t}=\frac{w_{i,t}}{\sum_j w_{j,t}}.
```

### 1. 手算四轮

取 $`\eta=\log 2`$，每天结束后观察到的损失如下：

| 日期 t | 专家 A | 专家 B |
|---|---:|---:|
| 1 | 0 | 1 |
| 2 | 1 | 0 |
| 3 | 0 | 0 |
| 4 | 1 | 0 |

求四天开始时的 $`p_{A,t}`$、$`p_{B,t}`$，以及算法累计损失 $`L_{\mathrm{alg}}`$。

### 2. 后见之明基准

定义：

```math
L^*=\min_{i\in\{A,B\}}\sum_{t=1}^4\ell_{i,t},
\qquad
R_4=L_{\mathrm{alg}}-L^*.
```

求第一问的 $`L^*`$ 与 $`R_4`$，并解释此基准与“每天都选择当天表现最好的专家”有何不同。

### 3. 一般上界

推广至 K 个专家、T 天，损失仍在 [0,1]，初始权重相同。

允许使用以下不等式（无需证明）：对任意分布 p 和位于 [0,1] 的损失，均有

```math
\log\left(\sum_i p_i e^{-\eta\ell_i}\right)
\le -\eta\sum_i p_i\ell_i+\frac{\eta^2}{8}.
```

研究总权重 $`W_t=\sum_i w_{i,t}`$，证明：

```math
R_T\le\frac{\log K}{\eta}+\frac{\eta T}{8}.
```

### 4. 学习率选择

选择使第三问上界最小的学习率 $`\eta>0`$，写出 Regret 关于 T、K 的增长阶，并解释平均每日 Regret 的含义。

**附加挑战：** 若每天只能观察自己实际选择的那个专家的损失，而不能观察其他专家的损失，原算法与证明中哪一步不再直接成立？问题将变为哪类在线学习问题？
