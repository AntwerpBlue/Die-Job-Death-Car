## 20261026-01 · 收集全部市场状态需要多久？
**难度：★★☆☆☆｜5–10 分钟｜Coupon Collector / Markov Chain / Inclusion-Exclusion**

每日独立等概率出现四个市场状态之一。T 为首次四种都至少出现过一次的天数。

1. 求 E[T]。
2. 已经观察十天但只见三种状态，求剩余等待时间期望。
3. 求 P(T≤6)。
4. 推广到 N 个等概率状态，求期望和大 N 渐近阶。

附加：四种状态概率不等时如何计算 E[T]？

## 20261026-02 · 带有测量误差的 Alpha 因子
**难度：★★★☆☆｜10–15 分钟｜Errors-in-Variables / IV**

真实收益 $Y=\beta F+\epsilon$，$E[F]=E[\epsilon]=0, Var(F)=1, Var(\epsilon)=\sigma_\epsilon^2, F\perp\epsilon$。观测 $X=F+u$，$E[u]=0,Var(u)=\sigma_u^2$，u 与 F、ε 独立；样本 iid。

1. 用 X 回归 Y 的 OLS 斜率概率极限。
2. $Corr(F,Y)$ 和 $Corr(X,Y)$ 以及噪声影响。
3. 新代理 $Z=F+v$，v 与 F、u、ε 独立；求 $\widehat{Cov}(Z,Y)/\widehat{Cov}(Z,X)$ 的概率极限。
4. 放松为 $Cov(u,v)=\rho\sigma_u\sigma_v$，讨论一致性。

附加：共享 Alpha 与共享测量噪声如何做数据验证。

## 20261026-03 · 密封报价拍卖中的最优策略
**难度：★★★★☆｜15–20 分钟｜Bayesian Nash / First-price Auction**

三名风险中性竞拍者私人价值 iid U(0,1)，密封提交非负报价，出价最高者获得并支付自己的报价；未赢者支付 0。假设存在对称严格递增可微均衡报价函数 b(v)，b(0)=0。

1. 若估值 v 但报 b(x)，其他人使用 b，计算获胜概率及预期收益 U(v,x)。
2. 用均衡条件 x*(v)=v 求 b*(v)。
3. v=3/4 的均衡报价及预期收益。
4. 换为第二价格密封拍卖时最优报价、两制度卖方预期收入及比较。

附加：效用 u(w)=√w、风险厌恶时第一价格拍卖报价如何变化？
