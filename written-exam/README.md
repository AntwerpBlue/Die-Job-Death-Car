## 记录约定
- 文件：`quizzes/YYYY-MM-DD.md`；题号：`YYYYMMDD-01`、`02`、`03`
- 题目文件只包含题目与明确条件，不提前公布答案。
- 复盘文件记录实际思路、有效方法、具体错误与知识薄弱点，不凭空认定“不会”。
- 定时推送与 GitHub 写入是两个独立动作：只有真正提交成功才算归档。
